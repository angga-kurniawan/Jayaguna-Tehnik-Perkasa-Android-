Aplikasi tetap menggunakan Firebase `jayagunatehnikperkasa`. Versi 1.2.3 menambahkan input banyak logo mitra sekaligus, masing-masing menjadi mitra tersendiri. Login Google, persetujuan Firestore, Drive langsung dari Android dan penghapusan akses admin oleh OWNER dipertahankan. Pengujian HP pribadi dan integrasi website produksi belum dilakukan agen.
